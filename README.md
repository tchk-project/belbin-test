# Командные роли — тест Белбина

Статическая веб-версия конкретного теста, выданного организатором волонтёрского проекта против буллинга. Это не новая редакция методики.

## Запуск

Откройте `dist/index.html` в браузере. В нём встроены все необходимые данные, стили и код. Интернет не нужен для прохождения. На некоторых браузерах сохранение при открытии через `file://` ограничено; для устойчивого сохранения разместите файл по HTTPS. Приложение сообщает об ошибке сохранения.

В каждом блоке распределяются ровно 10 баллов между восемью утверждениями. Допустимы 0 и целые 2–10. Новое прохождение начинается с нулей. Ответы и комментарии сохраняются в localStorage текущего браузера на текущем адресе сайта. Смена браузера, домена или очистка данных не переносит прогресс.

Результат: баллы всех восьми ролей, три наибольших и три наименьших результата с включением равенств на границе, таблица расчёта, дословные описания, личные комментарии. Доступны копирование, TXT и печать/PDF. Автоматической отправки результатов нет. При смене ответов ранее введённые комментарии остаются доступными.

## Источники и точность

PDF: `https://drive.google.com/file/d/1quFSD4G7Qun2iRBbZ8xVw_5J2XpLscAJ/view` и приложенная пользователем копия. Excel: «Тест Белбина.xlsx».

Формулировки и заголовки берутся из PDF. Переносы строк PDF объединены пробелами; слова, пунктуация и опечатки сохранены. Ключ на странице 4 PDF сверен со всеми 56 ссылками Excel. В Excel иной заголовок блока 7 (повтор блока 6), нет точки в конце №13, есть небольшие отличия пунктуации заголовков. Эти отличия не переносятся в веб-версию, основанную на PDF.

В инструкции PDF встречается «не превышала 10», но требуются распределение 10 и итог 70. Организатор отдельно уточнил: в каждом блоке ровно 10, 1 запрещён. Сайт соблюдает это уточнение.

Не заменять ключ на другие версии Белбина и не исправлять названия ролей самостоятельно. Контрольные ответы Excel используются только в тестах. В опубликованный HTML они не включаются.

## Разработка и проверки

Node.js 20+; внешние npm-пакеты не нужны.

```
npm run build
npm test
```

Для повторного извлечения источников нужны Python 3 и Poppler (`pdftotext`):

```
python scripts/extract.py /path/to/source.pdf /path/to/source.xlsx
npm run build
npm test
```

SHA-256 исходников записаны в `src/data.json`. Извлечение сверяет 56 ячеек ключа и тексты утверждений. `src/core.js` отвечает за подсчёт и валидацию, `src/app.js` — за интерфейс, `src/style.css` — за оформление, `scripts/build.mjs` — за автономную сборку.

## Публикация

Готовые файлы для любого статического хостинга: содержимое `dist/`.

### GitHub Pages

Pages настроен на публикацию из ветки `main`, папки `/ (root)`. Файл `index.html` в корне — автономная сборка теста. `npm run build` обновляет одновременно корневой `index.html` и `dist/index.html`; коммитьте оба файла. Workflow `.github/workflows/pages.yml` проверяет расчёт и соответствие сборки исходникам. Публикацию выполняет стандартный workflow GitHub Pages. Адрес: `https://tchk-project.github.io/belbin-test/`.

### Российский хостинг

Содержимое `dist/` можно разместить на обычном хостинге с HTTPS или в Yandex Object Storage с настроенным статическим сайтом. Облачный аккаунт, платёжный профиль и при необходимости домен остаются под управлением владельца. У приложения нет требований к серверному языку, базе данных или CDN. Не подключайте внешние CDN-шрифты или скрипты.

Выбор российского хостинга снижает зависимость от зарубежной доставки, но не является гарантией доступности. После публикации проверить сайт без VPN в домашней и мобильной сети РФ. Браузерное и сетевое тестирование из РФ в текущем окружении не выполнялось.

## Проверенные ограничения

Автоматически проверены вычисления, ключ, правила, сериализация, восстановление и сборка. Визуальная проверка и реальное прохождение в браузере пока не выполнены: штатного инструмента браузерной проверки в среде нет. Проверить вручную 360/390/768/1440 px, Tab/Enter, перезагрузку после частичного ответа, запрет единицы, сумму 8/10/12, копирование, скачивание и печать длинных комментариев.

«Поделиться PDF» создаёт полный PDF локально и передаёт его напрямую в системное меню отправки. «Печать / PDF» печатает тот же общий макет: диаграммы, таблицу расчёта, полные описания ролей, комментарии и ссылку на сайт. Макет и встроенный шрифт едины для SVG-печати и PDF. При отсутствии поддержки отправки файлов PDF скачивается; отмена отправки не вызывает скачивания. При ошибке отправки доступна отдельная кнопка скачивания. Ответы не передаются на сервер.

На мобильных экранах заголовок сохраняет пробел между словами; кнопки используют встроенные SVG-пиктограммы и текстовые подписи.
